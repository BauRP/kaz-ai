## Модернизация технической основы (отдельно от 25 функциональных процентов)

- GitHub Actions проверяет Node.js 26 LTS вместо 22.
- Зафиксированы Wrangler 4.158.0 и Playwright Core 1.65.0; используются современные HTML/CSS/JS без внешних CDN-скриптов.
- Добавлен воспроизводимый генератор preview и контроль точного совпадения между предпросмотром и основными файлами сайта.
- Dependabot раз в неделю предлагает обновления зависимостей, но не принимает их автоматически.
- Дополнительно проверено удержание фокуса клавиатуры внутри диалогов и восстановление фокуса после закрытия.

## Ограничения

- **Настоящие ответы GPT-OSS 120B пока не проверены** в подключённом Cloudflare. Реальная модель не запущена и публикация не выполнялась.
- Google-вход остаётся окном предпросмотра; настоящая авторизация не подключена.
- Сессионные чаты, проекты и личные инструкции исчезают при обновлении страницы.
- Браузерные автоматические проверки используют Chrome и тестовые ответы; они не подтверждают реальный облачный ответ ИИ.
- Версии прямых зависимостей закреплены, транзитивный lock-файл пока не зафиксирован.
