# Kaz AI — оболочка сайта

**Текущий этап:** только оболочка интерфейса для компьютеров и телефонов, без подключения искусственного интеллекта, Google и постоянного хранилища. Это не готовый работающий ИИ. Демо-сообщения существуют только в оперативной памяти открытой вкладки; после обновления исчезают. Данные не отправляются на сервер.

## Дизайн

«Орбитальный орнамент»: темно-синий космос, Земля, тонкие казахские орнаменты, бирюзовое сияние, отдельная светлая тема. Центральная зона отведена чату. В нижнем поле: плюс, выбор уровня, микрофон, стрелка отправки вверх. Никаких больших карточек «Текст / Код / Перевод / Расчёты» в центре.

Разделы: **Чаты**, **Проекты**, **Инструменты**, **Настройки**. Каталог включает 44 функции: все пункты 1–46 из пользовательского списка, кроме удалённого 12 и отсутствующего 26.

Уровни рассуждения: **Низкий** (Быстрые ответы), **Средний** (Баланс скорости и анализа), **Высокий** (Подробные рассуждения), **Углублённый** (Максимально глубокий анализ). Четвёртый недоступен до отдельного разрешения. Первые три — только настройки интерфейса до подключения GPT-OSS 120B.

Все будущие возможности пока честно показывают сообщение, что функция ещё не подключена. В том числе Google-вход, история, проекты, работа с документами, картинки, голос, поиск, глубокое исследование.

## Структура

- `public/index.html`: разметка экранов, визуальная композиция Земли и орнаментов.
- `public/styles.css`: темы, макет и адаптивность.
- `public/app.js`: интерфейсное управление и каталог всех будущих функций, без сетевых запросов.
- `public/favicon.svg`: самостоятельный знак Kaz AI в форме орнамента.
- `wrangler.jsonc`: Cloudflare Workers Static Assets.
- `tests/shell.test.mjs`: автоматическая проверка основных требований.

## Проверки

```bash
node --check public/app.js
node --test tests/*.test.mjs
```

В будущем локальный просмотр через Wrangler:
```bash
npm install
npm run dev
```

## Cloudflare

Настройка для Cloudflare Workers Static Assets уже есть. Команда публикации: `npx wrangler deploy`; отдельная сборка для чистого HTML/CSS/JS не требуется.

**Не публиковать без отдельного решения владельца.** При первоначальном тестировании доступ к сайту нужно ограничить через Cloudflare Access или другой способ: адрес `workers.dev` сам по себе общедоступен. Не добавлять секреты или токены в репозиторий.

## Установленные границы

1. Сначала оболочка. Затем лёгкие и средние функции. Сложные и очень сложные — строго после разрешения пользователя.
2. Поиск, источники, глубокое исследование, четвёртый уровень мышления, профессиональный вычислитель, внешние подключения — только заглушки.
3. GPT-OSS 120B, FLUX, Gemma 4, Whisper — выбранные модели, но **не подключены**.
4. Изображения, файлы, голос, видео — на более позднем этапе после текстовой части.
5. Google-регистрация — только будущее подключение, вопрос хранения истории и памяти не решён. Никаких скрытых решений относительно хранилища.
6. Кнопка «Поделиться разговором» исключена.
7. Нельзя объявлять неработающий AI или незавершённую авторизацию готовыми.
