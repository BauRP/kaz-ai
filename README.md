# Kaz AI — сайт и первая функциональная версия

**Состояние:** основная оболочка, сессионные чаты и проекты, базовые инструменты и подготовленный защищённый сервер GPT-OSS 120B. Облачная модель ещё не активирована, Google OAuth и постоянная история ещё не подключены.

Полный список требований и порядок этапов: [ROADMAP.md](ROADMAP.md).

**Прогресс текущей работы (только лёгкие и средние задачи):** [ACTIVE_PROGRESS.md](ACTIVE_PROGRESS.md). Машинные данные: [ACTIVE_PROGRESS.json](ACTIVE_PROGRESS.json). Прежняя оценка всех 44 функций остаётся архивной и не смешивается с процентом текущего этапа.

**Как открывать обновлённый сайт:** постоянный адрес предпросмотра — https://raw.githack.com/BauRP/kaz-ai/chatgpt/kaz-ai-shell-20261108/public/preview.html . Обычно достаточно открыть эту ссылку и нажать Ctrl+F5. Сервис предпросмотра может кэшировать содержимое ветки. Ссылка с конкретным SHA коммита всегда показывает закреплённую версию: Ctrl+F5 не заменит её на новую. Если кэш сохраняется, откройте новую ссылку с SHA последней версии.

## Готовность страниц перед добавлением в Google и Яндекс

- Заголовок главной страницы: **Kaz AI — Казахстанский искусственный интеллект онлайн**.
- Главная содержит обычный HTML-текст: назначение сервиса, будущие возможности текста/кода/перевода/картинок, планируемые **GPT-OSS 120B (~117 млрд)** и **FLUX.2 dev (32 млрд)**. Всего **около 149 млрд в двух отдельных нейросетях**, а не одной модели.
- Раздел [О Kaz AI](public/about/index.html) содержит кнопку «Открыть помощь». [Помощь](public/help/index.html) пока является отдельной кликабельной страницей-заготовкой, которая исключена из индексирования до появления полезного содержания.
- Отдельные страницы для запросов [ИИ-чат](public/ai-chat/index.html) и [Создание картинок](public/ai-images/index.html), плюс [Возможности](public/capabilities/index.html).
- Файлы [seo/sitemap.xml](seo/sitemap.xml) и [seo/robots.txt](seo/robots.txt) присутствуют в проекте как **шаблоны с `{{SITE_ORIGIN}}`**, не для непосредственного размещения. При опубликовании Cloudflare Worker уже выдаёт **настоящие** `/sitemap.xml` и `/robots.txt` с реальным доменом запроса. Неподтверждённый адрес в коде не подставляется.
- Никакой новый раздел не запускает ИИ-модель. Работа кнопок чата и прежняя компоновка сохраняются.

**Важно:** подготовка SEO и файлов не означает появление сайта в поиске. Для индексации нужен общедоступный опубликованный домен и подтверждение его в Google Search Console и Яндекс Вебмастер.

## Подготовка сайта для Google и Яндекса

Основной ИИ-чат оставлен без изменений. Добавлены обычные **HTML-страницы, читаемые без JavaScript**: `/about/`, `/capabilities/`, `/questions/`, `/privacy/`, `/kk/`, `/en/`. Это публичная информация о проекте, а не новые экраны чата.

- Настроены `robots.txt` и `sitemap.xml` через Cloudflare Worker на адресе опубликованного сайта.
- Неизвестные страницы должны возвращать реальный код **404**, а не выглядеть как существующая главная страница.
- Отдельная тестовая страница `preview.html` помечена `noindex`, чтобы поисковик не считал её второй копией сайта.
- У каждой информационной страницы есть уникальные заголовок и описание. С главного экрана на них ведут обычные ссылки.
- Добавлены безопасные заголовки `public/_headers` и проверки мобильного браузера без JavaScript.
- ИИ, картинки и Google-авторизация всё ещё не объявляются работающими, пока не подключены.

Аудит, границы достигнутого и дальнейшая проверка после публикации: [SEO_AUDIT.md](SEO_AUDIT.md). **SEO-код готовится отдельно; создание страниц не гарантирует индексацию или высокие позиции.** Для использования Google Search Console и Яндекс Вебмастера нужен окончательный публичный домен и опубликованная доступная версия.

## Современная техническая основа (ноябрь 2026)

- **HTML5, CSS и современный JavaScript** используются напрямую браузером. У языков нет номера «последней установленной версии»; проверяется корректность кода и реальное поведение в Chrome.
- **Node.js 26 LTS** используется для запуска проверок и сборки в GitHub Actions.
- **Wrangler 4.158.0** используется для сборки Cloudflare Worker. **Playwright Core 1.65.0** проверяет клики и клавиатуру в настоящем браузере. Прямые версии фиксированы в `package.json`.
- Скрипт `scripts/build-preview.mjs` собирает `public/preview.html` из `index.html`, `styles.css`, `app.js`, `session.js`, `i18n.js`. Проверка `npm run preview:check` обнаружит забытое обновление предпросмотра.
- GitHub Dependabot раз в неделю предлагает обновления инструментов и GitHub Actions в рабочую ветку. **Никаких автоматических слияний**.
- В CI запускаются проверки синтаксиса, интерфейса, доступности окон, API и сборка Cloudflare **без публикации**.

Для разработчика: `npm install` → `npm run preview:build` после изменений кода/стилей → `npm test`. Подключение настоящего ИИ и реальный Google-вход остаются отдельной задачей. Для будущей полной воспроизводимости транзитивных зависимостей потребуется lock-файл и `npm ci`; сейчас фиксированы только прямые версии инструментов.

## Уже работает в браузере (без внешних аккаунтов)

- Создание чатов и переключение между ними, временная история в памяти вкладки.
- Поиск по названиям и текстам сообщений.
- Переименование, удаление, закрепление чатов.
- Простые проекты: создать, переименовать, удалить проект; прикрепить чат к проекту. При удалении проекта сообщения остаются.
- Изменить сообщение, ответвить переписку, скопировать сообщение.
- Простая арифметика со скобками и четырьмя действиями без произвольного выполнения кода.
- Экспорт истории вкладки в TXT, без временных чатов.
- Временный чат, который не отображается в истории.
- Личные инструкции в памяти вкладки.
- Два оформления, меню языков RU/KZ/EN (полный перевод ещё не готов), три размера текста.
- Окна-заготовки для Google-входа, изображений, голоса и поздних функций.

Всё, что введено в эти сессионные инструменты, **исчезает после обновления страницы**. Нет локальной базы, облачной памяти и скрытого сохранения.

## GPT-OSS 120B: подготовлена защищённая интеграция

- Сервер `src/index.js` на Cloudflare Workers AI: `@cf/openai/gpt-oss-120b`.
- `wrangler.jsonc`: AI binding, маршрут `/api/chat`, статические страницы.
- Принимает только ограниченные текстовые запросы с секретным ключом `KAZ_AI_ACCESS_KEY`, который создаётся **в настройках аккаунта Cloudflare как Secret**, а не в GitHub.
- На сайте ключ вводится в специальном окне и хранится только до закрытия вкладки. В предпросмотре `preview.html` отправка запросов выключена.
- Три уровня рассуждения: Низкий, Средний, Высокий. «Углублённый» не активирован.
- Остановка запроса, сообщения об ошибках и отдельное уведомление о **реальном** превышении лимита.

**Серверный код подготовлен, но ответ реальной модели не подтверждён:** для этого необходимо настроить Cloudflare и закрытый тестовый адрес. Никакого публичного развёртывания автоматически не выполняется. `workers.dev` без Cloudflare Access не является приватным сайтом.

## Как проверить код

```bash
npm install
node --check public/app.js
node --check public/session.js
node --check src/index.js
node --test tests/shell.test.mjs tests/api.test.mjs
node --test tests/browser.test.mjs
npx wrangler deploy --dry-run --outdir /tmp/kaz-ai-build
```

Браузерный тест использует Chrome и пакет `playwright-core`. В GitHub Actions эти зависимости устанавливаются отдельно.

## Что строго отложено

- Подключение FLUX, Gemma, Whisper, создание/правка картинок и работа с файлами.
- Поиск и цитирование внешних источников, глубокое исследование.
- Четвёртый уровень рассуждений.
- Память между сессиями и облачная история.
- Интеграции с внешними сервисами.
- Настоящий Google-вход без настроенной OAuth-конфигурации.

**Удалённая функция «Поделиться разговором» не возвращается.** Новые сложные направления без разрешения не активируются.

## Приватный запуск

Перед открытием доступа через Cloudflare настроить закрытое тестовое окружение, Secret `KAZ_AI_ACCESS_KEY` (случайный длинный ключ, минимум 24 символа) и ограничения Cloudflare Access. Не сохранять ключи в публичном коде и не присылать их в чат. После настройки можно отправить тестовый запрос и подтвердить реальные ответы GPT-OSS.

## Структура

`public/index.html`, `styles.css`, `app.js` — оболочка; `session.js` — локальная функциональность; `preview.html` — отдельно собранный демонстрационный HTML; `src/index.js` — защищённый сервер Cloudflare; `tests/` — автоматические проверки.

Рабочая ветка: `chatgpt/kaz-ai-shell-20261108`. `main` не менять без отдельного разрешения.
