# Kaz AI: план разработки по сложности

Дата актуализации: 2026-11-08. Источник: «АЙ задачи.txt», решения из «10(2).txt» и последующее согласование дизайна в чате.

## Обязательные правила
- Всего 44 функции: исходные пункты 1–46, за исключением удалённого №12 «Поделиться разговором» и отсутствующего №26.
- Работа только над Kaz AI. Ветка: `chatgpt/kaz-ai-shell-20261108`. Основную ветку `main` не изменять без разрешения.
- Сначала лёгкие и средние функции, без самовольного перехода на сложные или отложенные мультимедиа.
- Сессионные разговоры и проекты пока существуют только в памяти вкладки. Ни облачной истории, ни постоянной памяти, ни реальной регистрации без отдельной настройки.
- Текущий макет: согласованная однотонная тёмно-синяя область. Не возвращать ранее удалённые фразы и большие карточки «Текст/Код/Перевод/Расчёты».
- Картинки FLUX, фотографии Gemma, аудио Whisper, работа с файлами, глубокое исследование и веб-поиск отложены по прямому решению владельца.
- Три рабочих уровня рассуждения low/medium/high при подключении модели. Четвёртый «Углублённый» только в интерфейсе до отдельного разрешения.
- Не открывать публичный AI API без защитного ключа и ограничений. Перед публикацией самого сайта обеспечить приватный доступ.
- Сообщение о дневном лимите показывать только после настоящего отказа от Cloudflare по лимиту, а не при обычной ошибке сети.


Текущие сопоставимые цифры готовности и прироста по всем 44 направлениям: [PROGRESS.md](PROGRESS.md). Машинные данные: [PROGRESS.json](PROGRESS.json).

## Ограничения готовности
- Временная история исчезает после обновления страницы. Это ожидаемое поведение до решения о постоянном хранении.
- Server Worker подготовлен и проверены параметры запроса по документации Cloudflare, но настоящие ответы Cloudflare GPT-OSS требуют настройки Secret `KAZ_AI_ACCESS_KEY` в аккаунте, AI binding и закрытого тестового развёртывания. Секрет никогда не сохраняется в репозитории.
- Авторизация Google пока только демонстрационное окно, без логина пользователя. Для настоящего входа нужны настройки в аккаунте и отдельное решение об идентификаторах пользователя.
- Инструменты, помеченные «Скоро», не должны притворяться готовыми.
- Файлы интерфейса и браузерные тесты должны проверяться в CI; не публиковать сайт автоматически.
