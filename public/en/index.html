What is Kaz AI?

Kaz AI is a web-based artificial intelligence service being developed in Kazakhstan. The goal is an accessible interface for communicating with AI in Kazakh, Russian and English.

What can you try today?

The current demo lets you create and rename conversations, search temporary chat history, organize chats into projects, choose a theme and interface language, and use a basic arithmetic calculator.

Chat history is currently kept only in the open browser tab. Refreshing the page clears it.

Which AI features are planned?

GPT-OSS 120B is the selected text model. A protected server integration has been prepared, but live public AI responses are not enabled or verified yet.

Image creation and editing using FLUX, file tools, voice functionality and web research are planned for later stages. The demo buttons do not yet run these models.

Is this a locally trained model?

Kaz AI is a Kazakhstan-based website project, not a language model trained from scratch. GPT-OSS and FLUX are models developed by other organizations. We describe the current development stage openly.
